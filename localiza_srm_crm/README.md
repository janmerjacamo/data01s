# Localiza SRM CRM Odoo 19

Módulo independiente. No depende de `localiza_studio_core` ni de otros módulos Localiza.

Dependencias estándar:
- base
- mail
- crm
- sale_management

Instalación:
1. Borrar por completo la carpeta anterior `localiza_srm_crm` del repositorio.
2. Subir esta carpeta nueva.
3. Actualizar Apps.
4. Instalar `Localiza SRM CRM`.

Nota Odoo 19:
No usa `category_id` en `res.groups` porque ya no es válido.
